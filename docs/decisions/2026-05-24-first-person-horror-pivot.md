# 方向决策：转向第一人称 + lo-fi 恐怖（大框架不变）

**日期：** 2026-05-24
**状态：** 已采纳，落地中

## 背景

游戏原为等距俯视的「治愈系新加坡人生模拟」。审视丰富度后，作者基于**自身美术/建模能力有限**的现实，决定转向**恐怖方向**——理由是恐怖游戏更能把弱美术变成优势、且更有市场：

- 黑暗 + 手电光锥 + 雾气天然遮丑，「看不清」本身即恐怖手段；
- lo-fi / PS1 画质 / VHS 噪点是成熟可卖的细分美学，粗模在黑暗里反而 uncanny；
- 新加坡题材在恐怖里几乎无人做 → 差异化卖点。

## 决策

1. **大框架 / 系统不变**：经济、时间、职业、身份、资产、关系、对话、存档、人生目标全部保留，作为「日常」的真实底色——日常越扎实，崩坏时越恐怖。
2. **第一人称是全局固定视角，贯穿始终**（不是只用于恐怖桥段）。等距正交相机看得到全场、反恐怖，弃用。
3. **恐怖按桥段「插入」**现有系统：农历七月（中元节）禁忌事件、新加坡都市传说随机事件、NPC 鬼故事——挂到时间日历 + 随机事件 + 对话系统上，纯代码即可起步。
4. **lo-fi 美学**（黑暗 / 雾 / 手电 / 噪点后处理）随场景工作逐步上。

## 已落地（本次）

第一人称视角改造（Plan 14）：相机挂胶囊眼高、`bUsePawnControlRotation`；鼠标视角走 legacy `Turn`/`LookUp` 轴（`DefaultInput.ini`，与 Enhanced Input 共存）绑 `AddControllerYaw/PitchInput`；WASD 改为相对视线方向移动；`bUseControllerRotationYaw=true`；自身占位身体对 owner 隐藏。现有 UI（菜单/对话）已有 `GameAndUI`+显示光标 / `GameOnly`+隐藏光标 的开关，与 FP 鼠标锁定/释放天然契合。64 测试无回归。

**待 PIE 复核（下次开编辑器顺手做）：** 鼠标灵敏度/眼高手感、`BP_PlayerCharacter` 子类对已删 `CameraBoom`/改名相机的继承是否干净。

## 后续

七月/都市传说恐怖事件层 → lo-fi 后处理与灯光 → 第一人称恐怖桥段 → 音效。
