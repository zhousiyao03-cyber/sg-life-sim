# ADR 0004: Pure Sandbox MVP, No Chapters/Main Story

- **Status**: Accepted
- **Date**: 2026-05-23
- **Decider**: Project owner (with Claude)

## Context

Brainstorm 阶段曾在三种游戏结构间犹豫：

- **方案 A：强主线章节式**（Disco Elysium / 太吾的梦中人风）
- **方案 B：纯沙盒永续模式**（Sims 风）
- **方案 C：章节 + 沙盒混合**（Persona 5 风）

Claude 最初推荐方案 C 并基于此写了 spec 第一版。但用户后来明确要求：

> "如果整体实现难度太高，我们起码可以先把这种模拟经营的策略玩法做出来。"

并选定 **方案 B**（Sims 式纯沙盒，无章节，玩家自定义人生）作为 MVP。

## Decision

**MVP 不做章节、不做主线、不做强制结局**。

- 时间线性推进（Persona 日历 + 时间块），但没有"第 X 章结束"的强制节点
- 玩家通过**软成就**驱动（"第一笔 $10K 存款" / "买到 BTO" / "拿到 PR"）
- 玩家**任何时候**可以主动选择 4 个软终局之一（扎根 / 兑现离开 / 心碎离开 / 漂着）

**Phase 3 才考虑加章节剧情**（如 DLC 或扩展）。

## Alternatives Considered

| 选项 | 写作量 | 系统设计量 | 重玩价值 | 适合一人开发 |
|------|--------|------------|---------|-------------|
| **方案 B：纯沙盒** ✅ | 低（10~15 万字） | 高 | 高（玩法驱动） | ⭐⭐⭐⭐⭐ |
| 方案 A：强主线章节 | 高（30+ 万字） | 低 | 低（剧情驱动） | ⭐⭐⭐ |
| 方案 C：混合 | 中（20~25 万字） | 中 | 中 | ⭐⭐⭐⭐ |

## Consequences

### 好处

- **写作量最少**。NPC 用对话模板 + 触发剧情，不需要每章手写过场。
- **重玩价值最高**。每次新游戏玩家会探索不同的成就组合 / 投资策略 / 关系网。
- **MVP 可以快速发布**。不依赖剧本完整度，系统跑通就能上 Early Access。
- **跟 Sim 模拟经营定位匹配**。玩家的乐趣来源是"建造自己的人生"，不是"看作者讲的故事"。

### 代价

- **没有明确 narrative hook**。Steam 商店页很难用"一句故事简介"吸引人。需要靠 vibe + 美术 + 系统深度做营销点。
- **"为什么继续玩"靠玩家自驱**。系统平衡和成就设计的质量决定一切。如果数值无聊，玩家 2 小时弃游。
- **NPC 关系故事弧的"弧度"会比主线游戏浅**。需要在 spec §7.2 列的 10 个关键 NPC 上做足深度，每个有自己的小故事弧。

## Implementation Implications

- TimeSystem 设计无章节切换逻辑（spec §6.1）
- ProgressSystem 用软成就而非"章节完成"判定（spec §6.4）
- 终局由玩家主动触发（菜单选项），不由剧情推进强制（spec §6.5）
- NPC 对话用 DataTable + 触发条件（关系等级 / 时间 / 玩家状态），不用编剧顺序脚本

## When to Revisit

- MVP 发布后玩家反馈"剧情薄"，考虑 Phase 3 加章节
- 如果 Phase 2 验证玩家普遍在某个时间点弃游（如玩 5 小时后无目标），可能需要引入"软章节锚点"
