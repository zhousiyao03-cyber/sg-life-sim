## 0. 摘要（TL;DR）

**新加坡人生模拟经营游戏**，UE5 + 等距俯视 45° + 一人开发 + meshy.ai 美术管线。玩家扮演一个外来程序员，从抵达樟宜机场的那一天开始，在 CBD 上班、攒钱、买房、买车、投资，最终决定这座岛是不是自己的家。

**MVP**：纯沙盒模拟经营（无章节、无主线、菜单跳转场景）。
**Phase 2**：开放街区 + 步行 / 开车解锁城市。
**Phase 3**：可选扩展（多职业 / 多结局 / 季节节日 / DLC）。

## 1. Vision

> 一个外来程序员在新加坡用五年时间证明自己的故事 —— 你在 CBD 写代码、在组屋区吃饭、在地铁里幻想、在房贷计算器前发呆，最后决定这座岛是不是你的家。

**目标玩家**：
- 中文互联网打工人（核心受众）
- 国内对新加坡工作 / 移民有想象的人
- 在坡真实打工的中文用户（自带传播）
- 模拟经营游戏爱好者（《模拟人生》/《潜水员戴夫》/《Game Dev Tycoon》/《Cart Life》用户）

**情感钩子**：
- 阶级跃迁的真实焦虑（HDB 涨到 $1M、PR 抽签、CPF 计算、币圈梭哈、被裁员）
- 陌生城市的温柔（食阁阿姨、楼下保安 Uncle、印度同事的太太、华侨小学同学聚会）
- 外来者的孤独 + 偶尔的归属感

## 2. 设计支柱（Pillars）

所有功能必须服务其中一个，否则砍。

### Pillar 1：打工人的真实感
工作 / 通勤 / 房租 / CPF / 投资 / 续签焦虑必须有体感，不是数字 UI。看到 ERP 涨价会心痛，看到 HDB 涨到 $1M 会窒息，看到组里印度同事突然被裁员会沉默。

### Pillar 2：陌生城市的温柔
治愈调性是底色。NPC（食阁阿姨、楼下保安 Uncle、印度同事的太太、华侨小学同学聚会）让玩家觉得"虽然孤独但有人"。

### Pillar 3：选择的重量（轻度版）
关键节点的选择（要不要接外包加班 vs 陪女朋友、买 BTO vs 买公寓、回国 vs 申请 PR）真实影响走向，但**不需要 Disco Elysium 级别厚度**。Persona 5 级别的"影响关系网 + 解锁不同结局"即可。

---

## 3. 玩家体验目标

- 单次游戏时长 **15~30 小时**
- 想"再玩一周目试试别的路线"（高重玩价值）
- 引发玩家朋友圈讨论："你买房了吗？你拿 PR 了吗？你给老家寄钱了吗？"
- 让在新加坡真实打工的中文用户感到**被看见**
- Steam 评分目标：90%+ 好评

---

## 4. 不做（明确砍掉，节省工程）

- ❌ 战斗系统（连推搡都没有）
- ❌ 警察 / wanted level / 犯罪
- ❌ 载具驾驶物理（车是 fast travel 道具 + 装饰资产）
- ❌ 多人 / 联机
- ❌ 角色创建器（固定主角）
- ❌ 全语音配音（首发只配关键 NPC 的几句关键台词，其他纯文本）
- ❌ Z 轴（楼内不可走，电梯 = loading screen）
- ❌ Disco Elysium 级写作量（NPC 模板 + 触发对话即可）
- ❌ MVP 阶段不做街道（菜单跳转场景）
- ❌ NPC 行人 AI（街道场景里行人 = 循环动画 + 简单 patrol）

## 5. 核心玩法循环

### 5.1 主循环（Macro Loop）

```
[赚钱] → [攒钱] → [消费 / 投资] → [属性 / 资产上升] → [解锁新能力 / 地点 / 选项] ↻
```

具体：
- **赚钱**：主业（CBD 程序员工资）+ 副业（外包 / 私活 / 投资收益）
- **攒钱**：扣除固定开销（房租 / 伙食 / 交通 / CPF / 税）
- **消费**：必需（生活）+ 进度（健身 / 学习 / 社交）+ 资产（车 / 房）
- **投资**：CPF / 定存 / SSB / REITs / SGX 股 / 加密货币
- **解锁**：买车 → Phase 2 开放街道（MVP 期是"扩大菜单地点"）

### 5.2 日循环（Micro Loop）—— Persona 日历 + 时间块

每天分 5 个时间块：

| 时间块 | 典型可选活动 |
|--------|------------|
| 早 | 早餐（影响心情 / 健康）/ 健身 / 早到办公室刷绩效 |
| 上午 | 工作（默认必经）/ 请病假 / 重要会议 |
| 下午 | 工作 / 摸鱼 / 接私活 / 重要会议 |
| 晚 | 食阁吃饭 / 健身房 / Bar / 约会 / 加班 / 学习 / 看房 |
| 深夜 | 睡觉（恢复能量）/ 撸代码 / 失眠刷币圈 |

每个活动消耗：**时间**（必然）+ **金钱**（多数）+ **能量**（多数）+ **心情**（影响关系 / 工作绩效）

### 5.3 周循环 —— 工资 + 账单
- 每月 1 号发工资（扣 CPF / 税）
- 每月 X 号扣房租 / 水电
- 每年 Y 月续签证 / 报税
- 每年 Z 月年终奖 + 调薪 review

## 6. 系统设计

### 6.1 时间系统
- Persona 5 风格的固定日历，时间是线性的
- 主菜单显示：日期 / 星期 / 季节 / 天气 / 当前游戏年（"在新加坡的第 X 年第 Y 个月"）
- 时间块选择活动 = 时间推进
- 周末规则不同（无主业，更多自由）
- 节日触发剧情（农历新年 / 国庆 / 屠妖节 / 中元节 / 圣诞）

### 6.2 经济系统（MVP 默认深度）

**收入科目：**
- 主业月薪（起点：$5000 SGD/月，逐年增长，跳槽可加 +30%~+50%）
- 副业（外包：$200~$2000 / 单 + 时间成本）
- 投资收益（季度结算）
- 年终奖（年薪的 0~3 个月）

**支出科目：**
- 房租（HDB 单间：$800 / 整租组屋：$2500 / 公寓：$3500+）
- 伙食（食阁 $5 / 餐厅 $30 / 高级 $100+）
- 交通（公交月票 $128 / Grab 单次 / 自己开车的 ERP + 油 + 停车）
- CPF（强制 20% 自付 + 17% 雇主代缴，分 OA / SA / MA 三账户）
- 税（年报税，分级累进）
- 通讯 / 水电杂费（固定 $200~$400 / 月）
- 大件消费（车 $80k~$200k SGD / 房首付 $50k~$500k）

**投资工具（精选 6 种，MVP 不做实时模拟，伪随机 + 事件驱动）：**
- **CPF OA / SA**：保底，2.5% / 4% 年息（默认 / 自动）
- **定期存款**：3~4% 年息，1 年起，锁定
- **SSB（新加坡储蓄债券）**：10 年阶梯式收益
- **REITs**：5~8% 股息，价格波动 ±20%/年
- **SGX 股票**（DBS / OCBC / SingTel 等少数代表）：波动 ±40%/年
- **加密货币**（一个虚构币 "SGCoin"）：波动 ±200%/年，可发生归零或爆涨事件

**经济事件（伪随机）：**
- 币圈崩盘 / 大涨
- 公司发奖金 / 削减预算
- HDB 政策变化（首付 / 利率调整）
- 利率变化（影响房贷 / 存款）

### 6.3 关系系统（轻度 Persona 5 风）

- **NPC 类型**：
  - 关键 NPC（约 10 个）：有名字 / 头像 / 完整故事弧（同事、室友、食阁阿姨、Bar 的常客、IT 部 ZhangSir、组长、女朋友候选人、PR 顾问、印度同事 Raj 的太太、华侨小学老同学）
  - 模板 NPC（约 30 个）：有姓名职业 + 触发对话池 + 1~2 个轻量故事弧
- **关系数值**：好感度 0~100，分等级（陌生 / 认识 / 熟悉 / 朋友 / 知己 / 恋人）
- **互动方式**：约吃饭 / 送礼 / 听吐槽 / 帮忙 / 拒绝帮忙
- **关系影响**：
  - 解锁副业（朋友介绍外包）
  - 解锁信息（PR 顾问告诉你政策）
  - 解锁结局（恋人 → 共同结局）
  - 触发剧情节点（同事被裁、室友搬走、女朋友吵架）

### 6.4 进度 / 属性系统

**主角属性（0~100）：**
- **健康**：影响能量上限 / 工作绩效 / 病假概率
- **心情**：影响关系建立 / 工作专注度
- **能量**：每天恢复，活动消耗
- **专业技能**：影响主业绩效 / 跳槽机会
- **社交**：影响关系建立速度
- **见识**：影响投资判断 / 解锁对话选项

**资产（数字 + 解锁项）：**
- 现金 / 银行 / CPF 余额
- 投资持仓
- 房产（无 / 出租屋 / 整租组屋 / 自购 HDB / 自购公寓 / 多套）
- 车辆（无 / Grab 月卡 / 二手车 / 新车 / 豪车）
- 身份（工作准证 EP/SP / 申请中 PR / PR / 公民）

**软成就节点（无强制，但驱动玩家）：**
- 第一笔 $10k 存款
- 第一次升职
- 第一笔 $100k 资产
- 第一辆车
- 第一套房（首付 / 全款 / 卖出）
- PR 申请提交 / 通过 / 拒绝
- 第一段恋情 / 结婚
- 第一次破产 / 失业
- 退休 / 离开 / 公民

### 6.5 失败 / 终局系统

**没有 hard fail**（玩家不会真的"游戏结束"），但有 4 种"软终局"：

1. **🌳 扎根**：拿到 PR + 买了房 + 稳定关系（或个人选择独居）。新加坡成为家。
2. **💰 兑现离开**：攒够钱主动回国。"赢得很现实"。
3. **💔 心碎离开**：工作准证续签失败 / 破产 / 关键关系破裂。"输给了城市"。
4. **🌃 留下但漂着**：PR 没拿，年年续签，租房，存款慢慢涨，关系网薄薄一层。"既不属于这里也回不去"。

玩家可以**任何时候主动选择结局**（菜单 → "我想结束这段人生"），或被剧情自然推到一种结局。

**重玩**：New Game+ 保留少量"上一周目记忆"（虚构）—— 比如解锁特殊对话选项、知道某些事件结果。

### 7.3 模板 NPC（MVP 约 30 个）

食阁顾客 / MRT 乘客 / 同事 / 邻居 / 健身房常客 等。模板化对话池 + 偶尔触发轻量小故事。

### 7.4 主线 / 章节
**MVP 阶段无章节、无主线。** 玩家自定义人生，软成就节点驱动。

### 7.5 写作量估算
- 关键 NPC：每个 5000~10000 字（含故事弧 + 关系阶段对话）= 5~10 万字
- 模板 NPC：每个 500~1500 字（含对话池）= 1.5~5 万字
- 系统文案（菜单 / 提示 / 物品描述 / 成就 / UI）：约 2 万字
- **总计：约 10~15 万字**（Disco Elysium 是 100 万字，所以是它 1/7~1/10）

## 9. 美术 / 视觉风格

### 9.1 视角
**等距俯视 45°**（正交相机），固定旋转角度，可微缩放。

### 9.2 美术风格
**风格化半写实**（不卡通也不写实，对标 Cult of the Lamb / Stardew Valley 3D 版 / Disco Elysium）：
- 色调：暖色为主，CBD 偏冷蓝 / 组屋区偏暖橘 / 食阁偏黄绿
- 描边：可选轻量 outline（toon shader），统一画风遮盖 meshy 风格漂移
- 灯光：UE5 Lumen，重氛围（夜雨反光、组屋楼道日光灯、CBD 落地玻璃）
- 雨天 / 夜晚是关键氛围场景（新加坡 = 永远的夏天 + 周期性雷暴）

### 9.3 UI 风格
- 主菜单 / HUD 模拟新加坡的两种典型 UI 美学：
  - **政府 / SingPass 风**（蓝白 + 无衬线 + 极简）—— 用于 CPF / 税 / 投资界面
  - **Grab / Shopee App 风**（绿白 + 圆角 + 卡片）—— 用于日常操作菜单
- 字体：中文用思源黑体 / 鸿蒙黑体；英文用 Inter / Roboto

### 9.4 音乐 / 音效
- 主基调：**新加坡 1990s~2010s 华语流行 + 现代 lo-fi**
  - 凤飞飞 / 邓丽君 / 蔡健雅 / 林俊杰 / 孙燕姿 / 梁文福 / 巫启贤 风格（不直接用版权曲目，原创 inspired-by）
  - 雨夜 / 深夜场景用 lo-fi hip-hop
- 环境音：MRT 报站、组屋楼下广东话广播、印度寺庙钟声、CBD 商业广播
- UI 音效：模仿新加坡常见提示音（SingPass 验证音、EZ-Link 滴卡音）

## 10. 技术架构（UE5）

### 10.1 引擎选型理由（再确认）
**用 UE5** 而非 Unity / Godot 的理由：
- Lumen 全局光照对氛围至关重要（夜雨 / 组屋楼道）
- Niagara 粒子系统适合雨水 / 雾气 / 食阁热气
- Blueprint 让一人开发更快迭代逻辑
- meshy.ai 导出 FBX 直接进 UE5
- 但**注意**：UE5 启动时间 / 编辑器开销大，对一人开发是负担。如果发现 UE5 太重，可考虑切换到 Unity 6（无 Z 轴 + 等距 + 一人开发 Unity 更友好）。**这个决策放在 MVP 起步后 2 周决定**。

### 10.3 核心系统模块（Blueprint + C++ 混合）

| 系统 | 实现方式 | 说明 |
|------|---------|------|
| `TimeSystem` | C++ + Blueprint | 日历 / 时间块推进 / 事件触发 |
| `EconomySystem` | C++ | 工资 / 账单 / 投资计算 / 经济事件随机 |
| `RelationshipSystem` | C++ + DataTable | NPC 好感 / 关系等级 / 互动响应 |
| `DialogueSystem` | C++ + DataAsset | 对话树（含条件分支 / 关系门槛 / 物品门槛） |
| `ProgressSystem` | C++ + DataTable | 软成就 / 解锁追踪 |
| `SaveSystem` | C++ | 全局存档 / 周目切换 |
| `LocationSystem` | Blueprint | 场景跳转 / 解锁地点 |
| `UISystem` | UMG | 各类界面 |
| `AudioSystem` | MetaSound | 音乐切换 / 环境音 |
| `EventSystem` | C++ | 经济 / 关系 / 时间事件总线 |

### 10.4 数据驱动（重要）

NPC 对话 / 经济事件 / 物品 / 投资工具 / 场景 / 成就 **全部数据驱动**（DataTable / JSON 导入），避免代码改动 = 内容改动。一人开发改 100 行 CSV 比改 100 个 Blueprint 节点快 10 倍。

工具链（计划）：
- Google Sheets / Excel → CSV → UE5 DataTable
- 对话用 [Ink](https://github.com/inkle/ink) 或自研简化对话脚本格式
- meshy → 一个 Python 脚本预处理 FBX（统一规模 / 命名）→ UE5 自动导入

## 11. 美术管线（meshy.ai + Mixamo + UE5）

### 11.1 资产分类与管线

| 资产类型 | 主管线 | 风格统一手段 |

### 11.2 风格统一关键
- **统一 prompt 模板**（所有 meshy 生成用同一前缀："风格化半写实 PBR 资产，等距俯视优化，统一暖色调"）

- **采样验证**：每批新资产先放到样板场景检查统一度，不通过的重做

### 11.3 一人 meshy 产能预估
- 道具：1 人 1 天可生成 + 修整 10~20 件 → 300 件道具约 15~30 天
- 建筑模块：1 人 1 天 1~3 个 → 20 个模块约 10~20 天
- 总计 MVP 美术产出约 **2~3 个月全职**（不含场景搭建 / 灯光 / 后期）

## 13. 风险 & 开放问题

### 风险（按严重程度排序）

1. **🔴 引擎选型风险**：UE5 对一人开发可能过重。MVP 起步 2 周内验证：能否快速搭出"日历 + 菜单 + 一个场景 + 一个对话框"原型？不能就考虑切 Unity 6。
2. **🔴 写作量风险**：10~15 万字对一人是 6~12 个月写作量。需要早期写 1~2 个关键 NPC 完整故事弧验证手感和速度。
3. **🟡 美术风格统一风险**：meshy 风格漂移可能让游戏看起来"AI 生成感"。需要严格 prompt 模板 + UE5 后期处理。
4. **🟡 经济平衡风险**：模拟经营游戏的数值平衡是无底洞。MVP 用一套保守数值上线，根据玩家反馈快速迭代。
5. **🟡 主题敏感风险**：涉及 PR 申请、外来劳工、HDB 政策、印度移民等议题可能在新加坡本地引发讨论。需要尊重 + 准确 + 避免刻板印象。
6. **🟢 美术产能风险**：meshy 月费 + 调整时间。提前预算。
7. **🟢 商业化风险**：模拟经营 + 中文优先可能在 Steam 国际市场受限。Early Access 期间根据数据决定是否英文本地化。

### 开放问题（在 review / writing-plans 阶段决定）

- 主角姓名（候选：陈鹤 / 林一 / 张然 / Other）
- 主角性别（固定男 / 固定女 / 提供二选一）
- 首发城市区域选择（建议：以"虚构合成区"代替真实区，避免本地敏感）
- 经济数值的具体平衡参数（首版用保守默认）
- 投资工具是否进一步精简（6 种是否太多 / 太少）
- 关键 NPC 的具体性格与故事弧（spec 阶段先列大纲，writing-plans 阶段细化）
- 节日剧情的优先级（MVP 是否包含至少 1 个完整节日？）
- 教程怎么做（强制引导 vs 渐进解锁 vs 完全自由）
